# Centered constellation headings — visual review

This Draft PR experiment displays three full-width GIFs in a **single README paragraph**, eliminating Markdown block margins between images. Each GIF draws a centered heading scaled to its native image width: **67 px for Languages (1600px canvas), 50 px for Frameworks and Tools (1200px canvases)**, so all three appear about the same size when GitHub renders them at equal README widths. The heading was 40 px in an earlier draft and 25 px in the original. Subtitles are enlarged for readability and normalized to the display width: **29 px on the 1600px Languages canvas** and **22 px on the 1200px Frameworks and Tools canvases** (previously 17 px on all three). Their center alignment and placement remain unchanged; the renderer checks for title collision, horizontal overflow and intrusion into the body image. The repeated "YT-TECHDEV / SKILL CONSTELLATION" eyebrow line has been removed from all three sections. Each original source GIF is immutable.

The output is produced by `scripts/render_centered_constellation.py`. The renderer reuses exactly the per-frame RGB colors already present in each approved source GIF, preserving **all pixels between y=120 and the bottom of the retained image** and the original frame count, duration and looping. The Languages image is cropped by 54 px at the bottom to remove only its footer rule and footer labels, with enough separation below the Shell / BAT label. Frameworks and Tools retain their original full heights. New headings occupy the original header region. The generator rejects color loss, particle differences, heading shimmer or timing changes.

Because GitHub sanitizes inline CSS, this preview relies on contiguous `<img width="100%" align="top" />` elements inside a single paragraph instead of `margin:0`. **True zero CSS line-box spacing is not guaranteed**; inspect the rendered README on desktop and 320/375px mobile before merging. No original images, particle physics, or original generators are modified.
